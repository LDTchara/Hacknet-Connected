# 模组兼容

## 基于 Action 的模组（KE、KaguyaTrial 等）

AC 的 PlayerActionTriggeredEvent 已覆盖。
Action 执行时框架拿到完整 XML，原样广播给其他客户端。
模组不需要修改代码。

## 需要状态同步的模组（KE CustomTrial、PhaseSwift 等）

需要实现 ISyncableState 接口（Serialize/Deserialize）。
未来 KE 可以加，预计两三百行。

## Sequencer（原版 + ExtensionSequencer）

每个人都开一个本地 Exe。
启动前投票准备（1/4 → 2/4 → 3/4 → 4/4）。
启动后各跑各的状态机，只有共享效果（删节点、崩溃）需广播。

## 多人化扩展需要声明的东西

每条 Action/Mission 需要两条属性：
- `isPublic`：是否全局事件
- `filter`：筛选器，按玩家条件匹配（如 rank、flag、连接状态等）

不填 isPublic 走默认值（默认值按 Action 类型区别对待）。


---

## 当前决定的兼容策略

### isPublic 默认值

不填 isPublic 走类型默认值。Faction Action 默认 false，其他默认 true。
详见 `07-isPublic设计.md`。

### 事件系统不改

AC 明确说 ServerClientEventsMod 保持现状，不再新增事件类型。
服务端不是通过手写加载代码解析扩展，而是跑一份完整游戏实例。

### 旧扩展兼容效果

| 场景 | 共享 rank 下效果 |
|------|----------------|
| Faction Action 触发 | 只触发一次 ✅ |
| AddIRCMessage | 不重复 ✅ |
| CopyAsset / AppendToFile | 只执行一次 ✅ |
| Flag 修改 | 共享 rank 下只需一人触发 ✅ |
| 玩家电脑文件 | 各人各管 ✅ |
| 任务状态 | 共享，一起推进 ✅ |
