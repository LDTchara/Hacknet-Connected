# 三层架构全面分析

基于 `save_LDT.xml`（35579 行，2.3MB，原版 HN + DLC 存档）和 `save_25.xml`（KE 测试扩展存档）。

## 结构总览

```
HacknetSave
├── DLC
├── Flags
├── NetworkMap (168 节点)
├── mission
├── branchMissions
├── AllFactions
└── other
```

## 世界层（World Layer）

服务端权威，所有玩家看到一致。改之前需要验证。**增量同步给所有在线玩家。**

| 存档元素 | 说明 | 必须同步？ |
|---------|------|-----------|
| `HacknetSave` 属性 | `generatedMissionCount`, `DLCMode`, `DisableEmailIcon` | 否 |
| `DLC/Flags` | `OriginalFaction` | 否 |
| `DLC/OriginalVisibleNodes` | 初始可见节点列表 | 是 |
| `Flags` | 全局 Flag | 是 |
| `NetworkMap/<computer>` 节点定义 | `name`, `ip`, `type`, `spec`, `id` | 是 |
| `ports/<Original>` | 端口原始编号 | 否（不可改） |
| `links` | 网络拓扑 | 是 |
| `firewall` | 防火墙配置 | 是 |
| `<daemons>` | 非玩家节点守护进程 | 是 |
| `<filesystem>`（非玩家节点） | 共享节点上的文件 | 是（大，IRC 日志、exe 文件）|
| `mission` | 当前任务 | 是 |
| `branchMissions` | 分支任务 | 是 |
| `AllFactions/<CustomFaction>` 定义 | `name`, `id`, `neededVal`, Action 列表 | 是（大，IRC 对话内容）|
| `AllFactions/<CustomFaction>` 共享状态 | `playerHasPassed` | 是 |
| `other/music` | 当前音乐 | 否 |
| `other/homeNode` | 主节点 | 是 |
| `other/homeAssetsNode` | 资产节点 | 是 |

**必须同步的条件：** 任何玩家改变了上述任意一项。
比如破解节点防火墙、触发 Faction Action、新增 IRC 消息到共享节点。

## 玩家层（Player Layer）

服务端每玩家存一份，离线冻结，重连时增量同步给对应玩家。**不需要同步给其他玩家。**

| 存档元素 | 说明 |
|---------|------|
| `DLC/Active` | DLC 是否激活 |
| `DLC/LoadedContent` | 同上 |
| `NetworkMap/<visible>` | 地图可见节点列表 |
| `NetworkMap/<computer spec="player">` | 玩家电脑 |
| `ports/<Number>` | 端口当前值 |
| `admin` | 破解状态 |
| `users/<known>` | 玩家发现了哪些用户 |
| `location` | 节点布局 |
| `computer/@icon` | 节点图标 |
| `<Memory>` | 各节点内存使用记录 |
| `<filesystem>`（玩家电脑） | 玩家自己电脑上的文件 |
| `Faction/playerHasPassed` | 玩家是否已完成该 Faction |
| `Faction/playerVal` | 玩家 rank |
| `DLC/Flags`（ConditionalActions） | 玩家触发的条件 Action 状态 |

## 临时层（Temporary State）

不同步。不落存档。各人各管。

| 内容 |
|------|
| 正在跑的 Exe 实例 |
| 终端历史 |
| RAM 用量 |
| Trace 倒计时 |
| Proxy 过载进度 |
| 通知/弹窗动画 |
| 主题色/动态特效 |
| 滚动位置/窗口状态 |

## 存档结构详情

### mission

当前在进行的主线任务。指向 Mission XML 文件路径。
多人下为世界状态（所有人在同一条主线）。

### branchMissions

分支任务列表。多人下：
- 共享 rank：所有人共享同一个 branchMissions 列表
- 独立 rank：每人各一看

### AllFactions

Faction 定义列表。包含每个 Faction 的：
- 名称、ID、需要的 rank 值
- 所有 Action 列表（IRC 对话等）
- playerHasPassed / playerVal

多人下 Faction 定义共享。playerVal 归属取决于 rank 模式。
