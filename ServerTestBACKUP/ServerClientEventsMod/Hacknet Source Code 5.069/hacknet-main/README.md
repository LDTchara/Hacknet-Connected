# Hacknet
A decompiled version of Hacknet aimed at researching the game code for modding purpose.
Please purchase your own copy to support the developer: https://store.steampowered.com/app/365450/Hacknet/

## Setup
Open the project with any IDE you like (Visual Studio, JetBrains Rider, etc) and compile the project. Then copy other missing files from your Hacknet installation to the output folder (like ./bin/Debug/net40, should not replace existing files) and you can now start the game.
