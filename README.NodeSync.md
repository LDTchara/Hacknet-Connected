# 节点同步：端口 / 代理 / 防火墙

> 状态：已写完，**未编译、未实测**。

## 默认：每人自己破解

节点的**端口、代理、防火墙**状态默认**不同步**：你打开的端口、打掉的代理、破解的防火墙只在你自己那里有效，别人要自己再破一遍。

想把进度给别人，用 `share` 命令（见下文）。

> 以前的版本会转发 `EVENT:PORT / FIREWALL / PROXY`，但收发两边的格式对不上，实际一直没生效，现在已经去掉。

## 共享节点：`<HNCShared/>`

扩展作者在节点 XML 里加这个自闭合标签，对应项就变成**全局共享**：

```xml
<Computer id="bankMain" name="Bank Mainframe" …>
  <HNCShared />                                              <!-- 端口、代理、防火墙全部共享 -->
  …
</Computer>

<Computer id="vault" …>
  <HNCShared ports="true" proxy="true" firewall="false" />   <!-- 只共享端口和代理；没写的属性 = true -->
</Computer>
```

| 项 | 共享后的规则 |
|---|---|
| 端口 | 任何人打开一个端口，所有人那里都打开 |
| 防火墙 | **分析进度共享**：所有人跑的 `analyze` 次数累加成一个全局次数（次数越多，输出里的干扰字符越少）。任何人 `solve` 成功，所有人都算破解 |
| 代理 | **过载进度共享，速率叠加**：每个人的 Shell 对代理造成的过载量都会扣在同一个剩余值上，几个人一起打就更快 |

- **有人连着就不重置**：共享节点上，只要还有玩家连着（主机或任何客户端），管理员就不会重置端口、防火墙、代理。各人的破解进度取并集，作为权威。
- **最后一个人离开时**：服务端按单机规则执行一次管理员重置，并同步给所有人。客户端掉线也算离开。
- **客户端本机的重置**（把代理充满、关端口、清防火墙进度）一律自动恢复，只有服务端的重置算数。这样主机当玩家时，主机离开节点不会清掉其他人的进度。
- **怎么识别共享节点**：开局后扫描扩展 `Nodes` 目录下所有节点文件，所以对旧存档同样生效。用动作动态添加的节点不在扫描范围内。

## `share` 命令

```
share <IP|节点id> [玩家名|P编号|all] [ports|proxy|firewall|all]
```

- 把**你在这个节点上已经破解**的东西分享给别人：开着的端口、已打掉的代理、已破解的防火墙。
- **默认**：分享给所有在线玩家（**包括服务端主机**），三项全部分享。
- **服务端主机**：在名单里是 **0 号 / `Server`**（和 `sendmail list` 一样）。客户端可以 `share <节点> Server` 只分享给主机；主机在服务端游戏里同样可以用 `share` 分享给客户端。
- **对方收到后**：在他本机生效，节点也会自动出现在他的地图上。
- **范围**：只分享破解进度，不分享管理员权限和账户密码。共享节点上本来就共享的项不会再分享。
- **例子**：
  - `share 10.0.0.5`：把这台电脑上能分享的都分享给所有人。
  - `share bankMain Bob ports`：只把端口分享给 Bob。

## 原理

- **服务端是权威**：服务端游戏里那台电脑的状态就是全局状态。
  - 客户端上报本机进展（`NODE_RPT`）：新开的端口、分析次数、破解、代理过载量（每 0.2 秒累计一次）。服务端把它们作用到自己的电脑上。
  - 服务端每 0.2 秒检查一次共享节点，有变化就广播 `NODE_STATE`。有玩家加入时全部重发。
- **客户端**收到 `NODE_STATE` 就写到本机电脑上，并以它为新基线。本机出现的进展会上报；本机出现的"倒退"会被恢复。
- **代理**：本机的 Shell 照常扣本机的剩余值（本地预测），服务端的值每 0.2 秒覆盖一次。几个人同时打时，进度条可能会有轻微跳动。
- **防火墙**：分析次数是 Hacknet 的私有字段 `Firewall.analysisPasses`，用反射读写。
- **分享**：`NODE_SHARE` → 终端按目标盖上发送者 → `NODE_SHARED` → 目标在本机应用。主机走管道（和玩家邮件一样），收发两端用同一份 `NodeShare` 逻辑。

| 位置 | 内容 |
|---|---|
| `Shared/NodeSync/NodeProtocol.cs` | 协议（终端和两个插件共用） |
| `Shared/NodeSync/SharedNodes.cs` | `<HNCShared/>` 扫描、节点状态编码 / 解码 / 应用、分享的组装与应用（`NodeShare`） |
| `ServerPlugin/NodeSync/ServerNodeSync.cs` | 权威：应用上报、广播状态；记录谁连着哪台共享节点，有人连着就拦下管理员重置（`SharedNodeAdminPatch`）；主机的 `share` 命令和接收分享 |
| `ClientPlugin/NodeSync/ClientNodeSync.cs` | 上报、应用、恢复本机重置；`share` 命令 |
| `HacknetServerTerminal/Lobby/NodeRelay.cs` | 转发上报和状态，处理分享 |

## 已知限制

- **只认节点文件**：只扫描扩展 `Nodes` 目录下的节点文件，动态添加的节点不能共享。
- **管理员权限**：没有同步，也没有分享，每人仍然要自己拿。
